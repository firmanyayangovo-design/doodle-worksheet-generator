# Doodle Worksheet Generator

A playful doodle-style worksheet generator for teachers using Google AI Studio.

## Features
- Generate custom worksheets with AI
- Doodle-style animations and icons
- Multiple question types
- Language support (Indonesian, English)
- Student-friendly UI

## Getting Started

### Prerequisites
- Node.js 18+
- npm or yarn

### Installation
```bash
npm install
```

### Development
```bash
npm run dev
```

### Build
```bash
npm run build
```
